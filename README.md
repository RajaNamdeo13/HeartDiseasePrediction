# Heart Disease Prediction using Machine Learning

This project uses machine learning algorithms to predict the likelihood of a person having heart disease based on clinical features. The aim is to help in early diagnosis using data-driven models.

## 📌 Features
- Data preprocessing and visualization
- Model training using multiple classifiers (e.g., Logistic Regression, Random Forest, etc.)
- Evaluation using metrics like accuracy, precision, recall, and F1-score
- Final model selection based on performance

## 🧠 Algorithms Used
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)

## 📊 Dataset
The dataset used is the **[UCI Heart Disease Dataset](https://archive.ics.uci.edu/ml/datasets/heart+Disease)**, which contains information such as:
- Age
- Sex
- Chest pain type
- Resting blood pressure
- Cholesterol
- Maximum heart rate achieved
- Exercise-induced angina
- ST depression

> The dataset is typically available via Kaggle or UCI ML Repository.
